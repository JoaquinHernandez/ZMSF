# ZMSF Reference Architecture

1. **Identity Layer:** Entra ID / FIDO2 / Passkeys
2. **Endpoint Trust:** TPM / EDR / Device Compliance
3. **Session Trust:** Device Binding / Risk Engine
4. **API Gateway:** Zero Trust Validation
5. **Business Services:** No Long-Lived Keys
6. **Encrypted Data Layer:** Mongo / PostgreSQL / Cosmos DB
7. **HSM Key Layer:** Azure HSM / Thales / CloudHSM
